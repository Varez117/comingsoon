# Portafolio · Christo Alvarez

Mi portafolio y CV en línea: quién soy, proyectos destacados, formación académica, certificaciones y contacto.

**Sitio en vivo:** https://varez117.github.io/comingsoon/

## Secciones

- **Inicio:** presentación con una animación de código que se escribe sola (merge sort en Python).
- **Experiencia:** perfil, ubicación, idiomas y tecnologías que manejo.
- **Proyectos destacados:** Noova, 2EXA (dashboard EXANI-II) y TR-AI-NER, con enlaces al código y a las demos.
- **Formación académica** en forma de línea de tiempo.
- **Certificaciones:** cada una se puede ver en PDF dentro de la página. En celular se abre en una pestaña nueva.
- **Contacto:** formulario que envía el mensaje por correo mediante [FormSubmit](https://formsubmit.co/), más redes sociales.
- **Modo claro y oscuro**, que se recuerda en el navegador.
- Diseño adaptable a celular con menú desplegable.

## Tecnologías

HTML5, CSS3 y JavaScript sin frameworks. Íconos de [Remix Icon](https://remixicon.com/) y [Devicon](https://devicon.dev/), tipografía Poppins.

## Uso local

```bash
git clone https://github.com/Varez117/comingsoon.git
cd comingsoon
python -m http.server 8000   # y entra a http://localhost:8000
```

Se recomienda usar un servidor local (en lugar de abrir el archivo directamente) para que el visor de certificados PDF funcione en todos los navegadores.

## Estructura

```
index.html   Contenido del portafolio
styles.css   Estilos, tema oscuro y diseño adaptable
main.js      Menú, tema, enlace activo, animación de código y visor de PDF
img/         Foto, capturas de proyectos, logo y favicon
src/         Certificados en PDF
```
